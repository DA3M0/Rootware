# Rootware SDK 开发者指南

SDK 位于 `sdk/`，核心库是 `librootware`。它是标准 Rust SDK，不再依赖自定义
`rwc` 命令；使用普通 `cargo` 创建和构建项目即可：

```sh
cargo new --bin hello
# 在 hello/Cargo.toml 中加入：
# librootware = { path = "../sdk/librootware" }
cargo build
cargo test
```

模板目录 `templates/` 仍可作为参考骨架：`service`、`driver`、`desktop` 和
`stack` 分别对应 IPC 服务、RKM、Qt/Vulkan 桌面和服务栈示例。SDK 构建阶段
使用系统 `rustc`/`clang`，不会下载或调用 LLVM。

Linux 模拟器位于 `sdk/simulator`，它提供与内核 IPC ABI 相同布局的内存传输，
用于单元测试和集成测试。真实 Rootware 运行时只需实现 `librootware::ipc::Transport`
即可接入系统调用。

服务实现 `librootware::service::Service`，由 `ServiceRegistry` 统一注册和管理
生命周期：

```rust
use librootware::service::{EchoService, ServiceRegistry};

let mut services = ServiceRegistry::new();
services.register(Box::new(EchoService::new()))?;
services.start()?;
// services.dispatch("echo", &request)?;
services.stop();
```
